# Control de Gastos - API REST

Aplicación full stack desarrollada con ASP.NET Core Web API y JavaScript.

## Funcionalidades

- Crear gastos
- Ver lista de gastos
- Eliminar gastos
- API REST con endpoints CRUD

## Tecnologías

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JavaScript (Fetch API)

## Descripción

Se desarrolló una API REST para la gestión de gastos y un cliente en JavaScript que consume los endpoints mediante fetch, permitiendo realizar operaciones CRUD.

## Cómo ejecutar

1. Ejecutar la API desde Visual Studio (F5)
2. Abrir `Frontend/index.html`
3. Interactuar con la aplicación
